# 图片转 LaTeX 像素拼图

一个纯浏览器运行的图片转 LaTeX 像素拼图工具。

上传图片后，工具会将图片缩放为指定像素尺寸，并把每个像素转换为由 `\textcolor`、`\rule` 等命令组成的 LaTeX 代码。横向连续且颜色相同的像素会自动合并，以减少生成代码的长度。

整个工具只有一个 HTML 文件，不需要服务器，不需要安装依赖，图片处理也在浏览器本地完成。

## 功能

- 图片本地导入与像素化预览
- 自适应像素：指定最长边，按原图比例自动计算另一边
- 自定义像素：分别设置宽度和高度
- 自定义尺寸超过原图实际像素时提示并阻止生成
- 横向相邻同色像素自动合并
- 生成 LaTeX 像素拼图代码
- 一键下载生成的 `.txt` 文件
- 高像素数量性能警告
- 单文件运行，无第三方依赖

## 使用方法

1. 下载仓库中的 `index.html`。
2. 使用现代浏览器直接打开。
3. 选择一张图片。
4. 选择“自适应像素”或“自定义像素”。
5. 调整目标尺寸并查看预览。
6. 点击“生成代码”。
7. 可以直接复制文本框中的 LaTeX，也可以点击“下载为文件”。

## 自适应像素

自适应模式只需要指定最长边。例如原图比例为 16:9，最长边设置为 48 时，工具会按照原图比例自动计算另一边，而不是强制生成 48×48 的正方形。

## 自定义像素与原图限制

自定义模式允许分别填写宽度和高度。

如果设置的宽度或高度超过原图本身的像素尺寸，工具会弹出提示并阻止生成。这个限制用于避免把低分辨率图片无意义地放大成更多“像素”。

## 性能警告

LaTeX 并不是为存储大量图片像素设计的。目标尺寸越大，生成的代码可能越长，浏览器需要处理的字符串和页面内容也会迅速增加。图片颜色越复杂、横向可合并的同色像素越少，生成结果通常也会越大。

当前版本按**总像素数**进行性能提醒，而不是把某个固定宽高当作“安全线”：

- 少于 50,000 像素：正常生成；
- 50,000～99,999 像素：页面提示“较高分辨率，生成可能较慢”；
- 100,000 像素及以上：生成前弹出性能警告，并允许取消。

例如 350×350 已经有 122,500 个像素，因此会触发性能警告。不同手机、平板、电脑和浏览器的承受能力差异很大，**不存在统一的安全分辨率**。

如果你仍然选择：

> 我知道了，继续炸我的浏览器

那么工具会继续执行。浏览器是否扛得住，取决于图片复杂度、生成结果、设备性能和浏览器环境。

在一次极端测试中，1400×1400（1,960,000 像素）曾导致浏览器页面直接崩溃；部分移动设备在远低于这一尺寸时也可能出现明显卡顿、无响应或页面崩溃。该案例仅用于说明风险，不代表 1400×1400 是固定阈值。

## 输出原理

工具先使用 Canvas 将图片缩放到目标尺寸，再读取像素颜色。对于每一行：

1. 从左向右读取像素；
2. 检测连续的相同颜色；
3. 将这些像素合并为一个更宽的 `\rule`；
4. 使用 `\kern` 与 `\raisebox` 定位；
5. 使用 `\textcolor` 设置颜色；
6. 最终组合为 LaTeX 代码。

透明像素会被跳过。

## 适合什么

这个项目更适合：

- 小尺寸像素画
- 图标
- 简单图案
- LaTeX 渲染实验
- 研究“图片能不能用 LaTeX 画出来”这种奇怪的问题

不太适合：

- 原尺寸照片转换
- 数百万像素的大图
- 追求高压缩率或高性能的图片存储

如果你在性能警告出现后仍然点击“继续炸我的浏览器”，工具会按你的选择继续尝试生成；请注意，不同设备的实际承受能力差异很大。

## 隐私

图片在当前浏览器页面中通过 Canvas 处理，本项目本身不会将图片上传到服务器。
